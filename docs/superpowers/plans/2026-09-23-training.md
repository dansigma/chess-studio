# Training Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Train mode on the Repertoire panel that accepts only stored moves from the current position.

**Architecture:** `trainingAttempt` decides whether a UCI is stored, refused, or the line is complete. The studio store keeps an unsaved training flag and session-start path, gates every control that would reveal or add a move, and applies an accepted move with path navigation. The Repertoire panel hides its move list and shows Train, Train again, and Stop.

**Tech Stack:** Next.js, React, Zustand, chess.js, node:test via `npx tsx`.

## Global Constraints

- Training starts at the position on the active board
- You find every stored move, for White and for Black
- A move that is not stored is refused and is not added to the tree
- Refused status is “Not in the repertoire.”
- Finished status is “Line complete.”
- Train again returns to the session start and clears the status
- Stop leaves the board where it is and forgets the session start
- Forward, notation clicks, repertoire row clicks, explorer moves, an engine line, and a null move do nothing while training is on
- Back still steps one move
- Opening a PGN or changing the active board turns training off
- An unapplied Setup Board draft is ignored
- No score, timer, or new dock tab
- Do not commit unless asked

```typescript
import assert from "node:assert/strict";
import test from "node:test";
import { Chess } from "chess.js";
import { trainingAttempt } from "./training.ts";
import { createEmptyTree, getFenAt, playMove, type GameTree, type Path } from "./tree.ts";

function playSans(sans: string[], tree: GameTree = createEmptyTree(), path: Path = []) {
  let state = { tree, path };
  for (const san of sans) {
    const chess = new Chess(getFenAt(state.tree, state.path));
    const move = chess.move(san);
    state = playMove(state.tree, state.path, {
      san: move.san,
      uci: `${move.from}${move.to}${move.promotion ?? ""}`,
      fen: chess.fen(),
      from: move.from,
      to: move.to,
    });
  }
  return state;
}

test("a stored move returns its path", () => {
  const game = playSans(["e4", "e5"]);
  const before = game.tree.children.length;
  const result = trainingAttempt(game.tree, [], "e2e4");
  assert.deepEqual(result, { kind: "accepted", path: [0] });
  assert.equal(game.tree.children.length, before);
});

test("an unknown move is refused", () => {
  const game = playSans(["e4"]);
  assert.deepEqual(trainingAttempt(game.tree, [], "d2d4"), { kind: "refused" });
});

test("a stored black move is accepted", () => {
  const game = playSans(["e4", "e5"]);
  assert.deepEqual(trainingAttempt(game.tree, [0], "e7e5"), { kind: "accepted", path: [0, 0] });
});

test("each stored reply is accepted", () => {
  const game = playSans(["e4", "e5"]);
  playSans(["e4", "c5"], game.tree, []);
  assert.equal(trainingAttempt(game.tree, [0], "e7e5").kind, "accepted");
  assert.equal(trainingAttempt(game.tree, [0], "c7c5").kind, "accepted");
});

test("no stored moves is complete", () => {
  const game = playSans(["e4", "e5"]);
  assert.deepEqual(trainingAttempt(game.tree, [0, 0], "g1f3"), { kind: "complete" });
});
```

- [ ] **Step 3: Implement the check**

```typescript
import { repertoireMoves } from "./repertoire";
import { getNodeAt, type GameTree, type Path } from "./tree";

export type TrainingAttempt =
  | { kind: "accepted"; path: Path }
  | { kind: "refused" }
  | { kind: "complete" };

export function trainingAttempt(tree: GameTree, path: Path, uci: string): TrainingAttempt {
  const moves = repertoireMoves(tree, path);
  if (moves.length === 0) {
    return { kind: "complete" };
  }
  const match = moves.find((move) => move.uci === uci);
  if (!match || !getNodeAt(tree, match.path)) {
    return { kind: "refused" };
  }
  return { kind: "accepted", path: match.path };
}
```
